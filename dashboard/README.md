# EP Dashboard

Interactive simulations and experiments used alongside the Embedded Programming lectures and tutorials.

- `web/index.html`: dashboard, topic search and experiment cards.
- `web/dashboard_flags.js`: visibility and construction badges for individual activities.
- `web/simulations/`: browser-based teaching simulations.
- `web/experiments/`: hardware-oriented experiments and their example sketches in `responses/`.
- `web/shared/`: serial communication, code display, sound and shared controls.
- `assets/branding/` and `web/assets/cards/`: logos and activity illustrations.
- `js/site_contact.js`: course contact details.
- `tests/`: existing simulation behaviour tests.

The root course build publishes this application automatically. Edit these files here; see the repository README for local preview and validation.
