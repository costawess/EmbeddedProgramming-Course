About this site

One publishable site, one teaching dashboard.

The root pages provide a simple public-facing website, while the `web/` folder keeps the interactive simulations and experiments organized for classroom use.

Why this structure works

Static hosting platforms such as GitHub Pages expect a clear root entry page. With this structure, the site opens at `index.html` and links students into the full interactive menu.

Where the learning content lives

The main dashboard remains inside `web/index.html`, with topic pages in `web/simulations/` and experiment pages in `web/experiments/`.

Recommended publish flow

  • Publish the repository root as the static site source.
  • Use `index.html` as the public landing page.
  • Send students directly to the dashboard button when they need the full app.
