    Cabin controls

    Single Elevator uses one cabin; Dual Elevator uses two. Each cabin carries up to three people. Changing tabs starts a fresh simulation. Manual mode lets you call elevators and assign a destination to each passenger. Random mode generates up to four waiting people and assigns destinations automatically. Choose one of five fixed seeds and a duration, select Random and press Start run to start a fresh repeatable run. The score sums each person's time from arrival until boarding, including people still waiting. Cabin score separately sums the time from boarding until the passenger disappears on exit, including time spent stopped inside the cabin. Lower is better. Scores remain visible after boarding and reset with each new run. Indefinite duration runs without a time limit. For a timed run, the entire simulation stops at the selected duration. The final score includes the accumulated waiting time of all people, including those still waiting at the deadline. Use UART commands to call elevators and select destinations from an ESP32. Movement and door timing run in the browser.
