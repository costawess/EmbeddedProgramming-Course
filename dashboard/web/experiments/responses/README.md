# Experiment Responses

This folder stores response files generated or collected for the experiment pages.

Subfolders:
- `coffee_machine`
- `dual_seven_segment`
- `intersection_controller`
- `kitchen_timer`
- `maze`
- `tic_tac_toe`
- `traffic_lights`

ESP32 UART sketches:
- `coffee_machine/esp32_coffee_machine_uart.ino`
- `dual_seven_segment/esp32_dual_seven_segment_uart.ino`
- `intersection_controller/esp32_intersection_controller_uart.ino`
- `kitchen_timer/esp32_kitchen_timer_uart.ino`
- `maze/esp32_maze_uart.ino`
- `tic_tac_toe/esp32_tic_tac_toe_uart.ino`
- `traffic_lights/esp32_traffic_lights_uart.ino`

Use each subfolder to keep logs, exported answers, screenshots, UART response samples, and now also the reference ESP32 code for that experiment.
