## How to study

1. Read a chapter and inspect its diagrams and examples.
2. Try the linked simulation to observe the behaviour.
3. Test the code on your board and complete the exercises.
4. Answer the quizzes before expanding **Check your answer**.

Use the expandable sidebar to browse every chapter. Code examples can be copied or downloaded; complete project sketches are provided with the timer, logic-analyzer, and state-machine chapters.
